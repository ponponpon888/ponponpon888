## 公開コードから見る代表作

### [SUMI Orchestrator](https://github.com/ponponpon888/sumi-orchestrator-oss)
**AI支援開発の「どこまで終わったか」「次に何をするか」を管理するCLI。**  
Git・CI・Vercel・Supabaseをまたぐ状態管理、完了条件と証跡、引き継ぎの設計を公開しています。READMEに同梱データのデモ手順があります。

### [AI Workforce](https://github.com/ponponpon888/ai-workforce)
**AIを使った開発の運用ルール・フック・検証キット。**  
SQL、秘密情報、設定変更、破壊的操作へのガードレールと、止める／通す両方の検証を扱います。公開用に書き起こした構成で、制約と測定結果も掲載しています。

### [IRレビュー・翻訳エージェント](https://github.com/ponponpon888/ir-review-agent)
**数値・用語の検査と、LLMによる文意レビューを分離する文書処理ツール。**  
Python / FastAPI。型による応答検証、未処理区間の明示、APIキーなしで動く検査経路を用意しています。

[各作品の見どころ・読む順番](https://github.com/ponponpon888/ponponpon888/blob/main/PORTFOLIO.md#コードと設計を読む)

## 技術と開発方針

| 分野 | 主な技術 |
| --- | --- |
| Webアプリ | TypeScript / Next.js / React |
| データ・基盤 | Supabase / PostgreSQL / RLS / Vercel |
| 外部連携 | LINE Messaging API / Claude API / Resend |
| ツール・自動化 | Python / PowerShell / GitHub |

AIを実装・調査・検証の補助に活用し、要件整理・設計判断・変更内容の確認を担当します。  
動作することに加えて、**何を検証し、何が未検証かを説明できること**を大切にしています。
